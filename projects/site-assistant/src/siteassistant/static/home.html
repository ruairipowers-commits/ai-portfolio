Ask the portfolio

Search and ask about the AI workflow portfolio

This service answers questions about the projects, the governance standard, the technologies and Ruairi's background, using only what's published on the blog, with a link to every page it used. It runs an open model locally on the portfolio's own server, so answers can be slower than a commercial assistant. Press Ask (bottom right) to try it.

Every search and question is logged as typed, without IP addresses, and the assistant reports each one to the portfolio's governance console, which can switch it off.
