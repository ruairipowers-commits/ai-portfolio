# Bayline Logistics — data we could offer (SYNTHETIC; Bayline Logistics is a fictional company)

We run a regional trucking network in the US Southeast and Midwest. Every load we move is recorded with origin and
destination, lane, weight, trailer type and the rate paid. We have about six years of history, updated daily, across
roughly 1,800 shippers. We think hedge funds might be interested in freight volumes as an early read on retailers and
manufacturers.
